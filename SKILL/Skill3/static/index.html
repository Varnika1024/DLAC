2. Inference stages

② Preprocessing — OpenCV converts the file bytes into an image array.
③ Model Execution — YOLOv8 Nano predicts vehicle locations.
④ Postprocessing — detected classes, confidence scores and boxes are collected.
⑤ Response — FastAPI sends JSON back to this page.
